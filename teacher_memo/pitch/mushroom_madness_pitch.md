## Today's New Challenge: Mushroom Madness!

* Direction & Walking: We'll code our player so they know which way they're facing and can smoothly walk left, right, and stop!

* Gravity Mechanics: We’ll learn how to add gravity to our game world so mushrooms actually drop down from the sky!

* Shooting Stars: We’ll program our star thrower with a cooldown timer using variables so you can fire at the falling mushrooms!

* Collision Explosions: We’ll write custom poof logic so when a star hits a mushroom, it triggers a mini explosion!
