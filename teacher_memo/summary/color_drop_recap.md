# Color Drop — Lesson Intro & Recap Pitch

## 🎨 Welcome Back! (Lesson Recap Pitch)

> **Teacher Instructions:** Read or adapt this quick, energetic pitch to open your class. It recaps what students built previously and sets the stage for today's coding goals!

---

### "Hey everyone! Welcome back to Code Camp! "

Before we jump into today's mission, let's take a quick look back at what we've already built in **Color Drop**! 🎨

* **Setting Up the Buckets:** We set up our bucket actors and gave them special setup functions to make sure gravity wouldn't pull them down and to show our score labels!
* **Smooth Controls:** We programmed key movement (and virtual controls for tablets) so our buckets move left and right. Remember fixing that sliding bug so the bucket stops moving when you let go of the key? That was awesome!
* **Screen Wrapping:** We wrote the `Reset` function so if our bucket moves too far off the screen to the left or right, it instantly pops up on the other side!
* **Lists & Random Colors:** We created our Color actors, renamed sprite sheets, and set up a **List** to randomly pick which color spawns into the game!
* **Spawning the Rain:** We updated the `Spawn` code in the Red Bucket so colors keep dropping continuously from the sky!
* **Collecting & Score Mechanics:** We coded the collection logic so catching the right color updates your score (remember, the middle buckets are worth the most points!).
* **Game Loop & Reset:** We programed the restart function and copy all our working code over to the Green, Blue, and Yellow buckets so all 4 buckets work seamlessly!
